# Working Agreement

We work as teammates.

## Rules
- One problem at a time.
- No giant speculative implementations.
- Decisions stay visible.
- Use experiments to resolve uncertainty.
- Major changes go through a decision entry.
- Prefer focused branches and pull requests.

## Every work update
**Done:** what changed  
**Evidence:** what proves it  
**Blocked:** what is uncertain  
**Next:** one next meaningful task

## Branch examples
- feat/resolver
- feat/raw-ir
- feat/architecture-graph
- feat/tensor-inspection
- research/model-selection

## Commit prefixes
feat:, fix:, test:, docs:, refactor:, research:
