# Release / Submission Checklist

## Product
- [ ] Core promise obvious in 10 seconds
- [ ] Architecture comes from actual artifacts
- [ ] Important nodes expose technical details
- [ ] Evidence is visible
- [ ] Unsupported cases fail honestly

## Engineering
- [ ] Tests pass
- [ ] Setup is reproducible
- [ ] No secrets or model weights committed
- [ ] Failure handling documented
- [ ] Demo performance acceptable

## Documentation
- [ ] README current
- [ ] Status current
- [ ] Decision log current
- [ ] Demo instructions work
- [ ] Architecture docs match code

## Demo
- [ ] One complete path
- [ ] Backup model
- [ ] Strong visual moment
- [ ] Strong technical moment

## Submission
- [ ] Repo clean
- [ ] Demo link works
- [ ] Pitch matches implementation
- [ ] Screenshots/video current
- [ ] Model/license credits checked
